# Trackit

A native click-track app for Mac and iPad, built for running click tracks at church — a from-scratch, feature-unlocked replacement for Playback (MultiTracks.com).

## Features

- True infinite click looping (no gap or restart glitch) via `AVAudioEngine`
- Tap tempo, adjustable time signature, and subdivisions (1/4, 1/8, 1/8T, 1/16)
- Song library and setlists, shared between the Mac and iPad apps
- Tempo search powered by [GetSongBPM](https://getsongbpm.com)

## Status

Early, personal-use build — not yet distributed. See `ClickTrackApp/` for the Xcode project (Mac + iPad targets sharing one codebase).
